The Platform

Power Platform의 다섯 영역

Microsoft Power Platform은 업무 솔루션을 빠르게 만드는 로우코드 플랫폼입니다. 다섯 영역은 따로 써도 되고, Microsoft Dataverse를 바탕으로 함께 연결해 쓸 수도 있습니다.

Agents

Copilot Studio

조직의 데이터와 시스템에 연결되는 AI 에이전트와 워크플로를 하나의 스튜디오에서 만들고, Teams 등 사용자가 일하는 채널에 배포합니다.

Microsoft Learn에서 보기 →
Apps

Power Apps

캔버스 앱과 모델 기반 앱으로 업무 앱을 만듭니다. Plans에 업무 시나리오를 자연어로 설명하면 테이블, 앱, 흐름, 에이전트까지 포함한 솔루션 초안이 만들어집니다.

Microsoft Learn에서 보기 →
Automation

Power Automate

클라우드 흐름으로 API가 있는 서비스를 연결하고, 데스크톱 흐름(RPA)으로 브라우저와 PC 프로그램의 반복 작업을 자동화합니다.

Microsoft Learn에서 보기 →
Analytics

Power BI

데이터를 시각화하고 분석해 조직 전체와 인사이트를 공유합니다. 자연어 Q&A와 분해 트리 같은 AI 시각화로 원인 분석을 돕습니다.

Microsoft Learn에서 보기 →
Websites

Power Pages

Dataverse와 연결된 외부 공개용 업무 웹사이트를 로우코드로 만들고 호스팅합니다. Copilot Studio 챗봇과 Power BI 보고서를 페이지에 넣을 수 있습니다.

    Microsoft Ignite 2026 개막

    11월 17일부터 20일까지 샌프란시스코 Moscone Center에서 Microsoft Ignite가 열립니다. 무료 디지털 패스로 기조연설과 세션을 온라인으로 볼 수 있고, 녹화본은 행사 후 다시 볼 수 있습니다.

    • 기조연설한국 시간 11월 18일(수) 새벽 3시 Satya Nadella와 Judson Althoff가 발표합니다. 현지 시간은 11월 17일 오전 10시이며, 일정은 바뀔 수 있습니다.
    • 세션BRK386 What's new in Power Platform Power Apps, Power Automate, Power Pages의 최신 기능과, 로우코드 개발과 에이전트 기반 개발이 하나의 플랫폼에서 결합되는 방향을 소개합니다.

    Copilot Studio와 Power Platform의 새 발표는 행사 후 이 페이지에 정리할 예정입니다.

  2. 2026.11.10

    10·11월 기능 업데이트: 업무 앱에 AI가 들어오다

    • 프리뷰Work IQ의 비즈니스 앱 자연어 대화로 모델 기반 앱 데이터를 찾고 만들고 고칩니다. 제출 전에 사용자가 변경 내용을 확인합니다.
    • 프리뷰AI 행 요약 모던 데이터 그리드에서 Dataverse 행을 AI가 요약합니다. ShowAIRowSummary 속성으로 켭니다.
    • 프리뷰모던 첨부 파일 컨트롤 여러 파일 선택, 썸네일, 드래그 앤 드롭을 지원하며 SharePoint 목록과 Dataverse에서 쓸 수 있습니다.
    • 프리뷰GitHub 연동 캔버스 앱 에이전트 편집 GitHub 로그인으로 에이전트가 캔버스 앱을 수정합니다. 사용량은 GitHub로 과금됩니다.
    • 프리뷰데스크톱 흐름 예약 트리거와 플로우차트 모드 클라우드 흐름 없이 Automation center에서 RPA를 예약하고, 실행 경로를 노드 그림으로 디버깅합니다.
    • 프리뷰관리자용 자연어 질의와 모니터 알림 환경·소유권·정책 현황을 자연어로 묻고, 모니터 알림을 Teams 등으로 보내며 지표를 OpenTelemetry 형식으로 내보냅니다.
    • 신규모던 컨트롤 4종과 데이터 그리드 페이지 나누기 Avatar group, Persona, Metrics card, Card gallery가 추가되었습니다.

    출처: What's new in Power Platform: October/November 2026 (Microsoft Power Platform Blog)

  3. 2026.09.17

    9월 기능 업데이트: 코딩 에이전트로 앱 만들기 정식 출시

    • GA캔버스 앱 authoring agent 플러그인 코딩 에이전트로 캔버스 앱을 만들고 수정합니다.
    • GA모델 기반 앱 빌더 스킬 자연어 요구사항으로 테이블, 폼, 뷰, 보안 역할까지 앱 전체를 생성합니다.
    • GA모델 기반 앱 새 헤더와 탐색 화면 공간이 넓어진 새 디자인을 선택해서 적용할 수 있습니다.
    • 프리뷰생성형 페이지에서 커넥터 데이터 사용 Dataverse 외에 SharePoint, SQL 데이터도 쓸 수 있습니다.
    • 신규Power CAT 실습 랩 20개와 Fluent 2 화면 템플릿 6종 교육 과정에 바로 활용할 수 있습니다.

  4. 2026.09

    릴리스 웨이브 종료, 상시 업데이트로 전환

    반기마다 묶어서 내던 릴리스 웨이브 방식이 2026 Wave 1을 끝으로 마무리되었습니다. 앞으로는 프리뷰와 정식 출시 기능이 수시로 나오고, Microsoft의 AI at Work Roadmap에 게시됩니다. 반기 계획 대신 변경 사항을 꾸준히 확인하는 운영 체계가 필요합니다.
